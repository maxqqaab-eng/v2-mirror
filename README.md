代理客户端（v2rayN）安装包的公开下载镜像，用于工具安装时的最后兜底线路。

## 下载

正式下载地址见 [Releases](https://github.com/maxqqaab-eng/v2-mirror/releases/latest)：

```
https://github.com/maxqqaab-eng/v2-mirror/releases/latest/download/v2.zip
```

文件：`v2.zip`（约 126.3MB），即 v2rayN 的 Windows 64 位自包含桌面版压缩包。
